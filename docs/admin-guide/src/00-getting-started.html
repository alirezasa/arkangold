    آشنایی با پنل و قواعد کلی

    این قواعد در همه‌ی ماژول‌ها یکسان است؛ پیش از هر کاری آن‌ها را بخوانید.

    ۱-۱. ورود به پنل

    1. نشانی پنل را باز کنید (در استقرار فعلی: https://admin.arkan.gold).
    2. نام کاربری و رمز عبور را وارد و ورود به پنل را بزنید.
    3. پس از ورود، منوی سمت راست فقط بخش‌هایی را نشان می‌دهد که نقش شما به آن‌ها دسترسی دارد.

    تنظیمات سیستم: مقادیر دقیق شروع کار

    مسیر: سیستم ← تنظیمات سیستم — فقط مدیر ارشد

    ۳-۱. نحوه‌ی ویرایش

    • هر کلید یک کادر دارد. مقدار را تایپ کنید و از کادر خارج شوید (کلیک بیرون یا Tab)؛ ذخیره خودکار انجام و عبارت «ذخیره شد» نمایش داده می‌شود. دکمه‌ی ذخیره‌ی جداگانه وجود ندارد.
    • کلیدهای بله/خیر یک دکمه‌ی «فعال / غیرفعال» دارند که با هر کلیک عوض می‌شود.
    • مبالغ ریالی هستند (فصل ۱-۳). ستون «مقدار شروع پیشنهادی» در جدول‌های زیر دقیقاً همان چیزی است که باید تایپ کنید.
    ستون «مقدار شروع پیشنهادی» یعنی چه؟

    برای کلیدهایی که به اطلاعات خود شرکت وابسته‌اند (شناسه‌ی ملی، شبا، …) باید مقدار واقعی شما وارد شود و ما قالب دقیق را گفته‌ایم. برای سیاست‌ها (سقف‌ها، کارمزدها) یک نقطه‌ی شروع محافظه‌کارانه پیشنهاد شده که پس از چند هفته کار واقعی با تصمیم مدیریت قابل تغییر است.

    اتصال سرویس‌های بیرونی

    پیامک، احراز هویت ثبت احوال (فینوتک) و درگاه پرداخت — جزئیات کامل در راهنمای ۱۰

    ۴-۱. پیامک (قاصدک یا sms.ir)

    بدون پیامک، کاربران کد ورود دریافت نمی‌کنند. ابتدا از پنل سامانه‌ی پیامکی خود کلید API و شماره‌ی خط را بگیرید.

    1. سیستم ← یکپارچه‌سازی‌ها: سرویس ارسال پیامک (SMS) فعال باشد؛ در فهرست Providerهای آن، قاصدک (و/یا sms.ir) را فعال و Mock (داخلی) را غیرفعال کنید. در نصب اولیه فقط Mock فعال است و پیامکی واقعاً ارسال نمی‌شود.
    2. سیستم ← مرکز پیامک ← تب «سامانه‌های ارسال» ← روی کارت «قاصدک» تنظیمات اتصال.
    3. فیلدها: API_KEY = کلید وب‌سرویس (پنل قاصدک ← تنظیمات ← وب‌سرویس)؛ LINE_NUMBER = شماره خط مثل 30005006009009. ذخیره.
    4. اولویت: قاصدک 1، sms.ir 2 (سامانه‌ی پشتیبان). اگر فقط یکی دارید، دیگری را غیرفعال کنید.
    5. فعال‌سازی ← استعلام اعتبار حساب (باید مانده‌ی اعتبار نمایش داده شود) ← ارسال آزمایشی به موبایل خودتان.
    6. سامانه‌ی «شبیه‌ساز (لاگ)» را در محیط واقعی غیرفعال کنید.
    قالب‌های OTP

    اغلب سامانه‌ها ارسال کد ورود از خط عمومی را فقط با «قالب تأییدشده» (Verify) اجازه می‌دهند. در تب «متن پیامک رویدادها» برای «کد ورود»، «کد ثبت‌نام» و «کد بازیابی رمز» نحوه‌ی ارسال را «قالب تأییدشده‌ی سامانه» بگذارید و نام قالب قاصدک (یا شناسه‌ی عددی قالب sms.ir) را وارد کنید.

    ۴-۲. احراز هویت (فینوتک)

    1. سیستم ← یکپارچه‌سازی‌ها (KYC/فینوتک) ← سرویس احراز هویت: Provider «فینوتک» را فعال و اولویت آن را 1 کنید و «Mock (داخلی)» را غیرفعال کنید (در نصب اولیه Mock با اولویت ۱ فعال است و هر کد ملی معتبری را بدون استعلام واقعی تأیید می‌کند!). اگر برای «تطبیق شبا و کد ملی» و «تطبیق کارت و کد ملی» هم Provider فهرست شده، فینوتک را برای آن‌ها هم فعال کنید.
    2. بخش «Credential های فینوتک».
    3. CLIENT_ID و CLIENT_SECRET = شناسه و رمز کلاینت از پنل فینوتک؛ NID = کد ملی ۱۰ رقمی صاحب کلاینت.
    4. دکمه‌ی تست اتصال را بزنید؛ باید «موفق» شود.
    5. در تنظیمات سیستم، identity.finotech.sandbox را برای محیط واقعی روی غیرفعال (false) بگذارید.

    ۴-۳. درگاه پرداخت

    1. سیستم ← تنظیمات سیستم ← بخش «درگاه‌های پرداخت».
    2. زرین‌پال: Merchant ID (۳۶ کاراکتری) را وارد کنید، تیک «حالت آزمایشی» را بردارید و دکمه را روی «فعال» بزنید.
    3. به‌پرداخت ملت (در صورت داشتن قرارداد): Terminal ID، Username و Password وب‌سرویس را وارد و فعال کنید.
    4. payment.gateway.callback_base_url = https://api.arkan.gold (نشانی API، نه سایت).
    5. یک واریز ۱۰ هزار تومانی آزمایشی از اپ انجام دهید و در مالی ← تراکنش‌های کاربران ببینید.

    ۵-۲. آزمون پذیرش پیش از افتتاح

    • یک کاربر آزمایشی ثبت‌نام و احراز هویت کند (کد پیامک برسد، فینوتک تأیید کند).
    • واریز با درگاه و واریز کارت به کارت انجام و تأیید شود؛ موجودی کیف پول درست باشد.
    • خرید و فروش طلا انجام شود؛ در حسابداری ← دفتر روزنامه سند سیستمی هر کدام دیده شود.
    • درخواست برداشت ثبت، تأیید و با شماره‌ی پیگیری بانکی «پرداخت‌شده» شود؛ پیامک‌ها برسد.
    • یک سفارش فروشگاه پرداخت، ارسال و با کد تحویل مشتری تحویل شود.
    • حسابداری ← مغایرت‌گیری: همه‌ی ردیف‌ها سبز؛ تراز آزمایشی: «تراز صحیح است».
    • خزانه ← پوشش و خرید طلا: کسری ایجادشده از خرید آزمایشی دیده شود.
