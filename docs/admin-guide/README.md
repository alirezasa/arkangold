## ویرایش و ساخت مجدد

منبع هر راهنما `src/*.html` و قالب مشترک `assets/guide.css` است. پس از ویرایش:

```bash
# یک‌بار در یک پوشه‌ی موقت
npm i playwright-core pdfjs-dist@4 pdf-lib

# همه‌ی ماژول‌ها یا فقط چند ماژول (با پیشوند نام فایل)
DEPS_DIR=/path/to/that/folder CHROMIUM=/path/to/chrome node docs/admin-guide/build.mjs
DEPS_DIR=... CHROMIUM=... node docs/admin-guide/build.mjs 03 04
```

فهرست مطالب و شماره‌ی صفحه‌ها خودکار ساخته می‌شود (`data-toc` روی فصل‌ها و `h2[data-toc]`)؛ جلد بدون سربرگ و پاورقی چاپ می‌شود.
